# ③ Shot execution

Use for turning an approved shot plan and inspected assets into a generation-ready video prompt, or diagnosing and revising a failed shot.

## Read

- [Project workflow](../project-workflow.md) for input versions, media records and handoffs.
- [Prompt delivery](../prompt-delivery.md) for self-contained prompts, bilingual output, Element syntax and delivery checks.
- [Prompt and shot guide](../prompt-and-shot-guide.md), [Studio controls](../studio-controls.md), and only the selected Studio-version reference.
- Read the relevant performance, space, dialogue or high-constraint reference only when the shot requires it; use [platform access](../platform-access.md) for any read-only platform discovery.

## Responsibilities

- Compile ①'s approved camera, action, performance and sound plan against ②'s effective assets and the required adjacent state.
- Where supplied, adapt the current behavior/voice baseline to this shot using [actor performance](../actor-performance-and-facial-actions.md); take observed carryover from the relevant media or ⑤'s selected interval. Do not copy the full character profile or replace the recognized baseline with a generated accident.
- Inspect the relevant images before presenting a dependent prompt as ready to use. Identify missing evidence and keep an asset-dependent draft conditional until its critical inputs are ready.
- Express the scene's lighting from the selected camera position and keep the prompt and verified controls compatible with the approved lighting baseline.
- Maintain the video prompts and generated-media record: prompt/control version, asset references, actual result identifier, observed or user-reported status, and material failures. A prompt alone is not evidence of generation.
- Diagnose the responsible cause and its necessary dependencies before proposing a retry; return creative or asset changes to their owners.

## Boundaries

The director performs uploads, page binding and Generate. This role may inspect the page read-only within scope, but does not change page selections, submit jobs or spend credits. Do not invent a web control from an API field, change approved performance, or mark a result accepted on the director's behalf.

## Deliver and hand off

Deliver the applicable controls, one complete bilingual video prompt and only the material acceptance checks specified by the shared guides. Hand ④ the actual result, input versions and any unverified audio or visual details; hand ⑤ available candidate media and limitations. ⑤ owns proposed and actual edit intervals. Send confirmed state changes to ① as links to the updated media record, not a duplicate ledger.
