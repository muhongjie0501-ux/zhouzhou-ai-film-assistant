# Sources, evidence dates and public-release provenance

Read this for a disputed platform claim, source attribution, or an authorized refresh. Ordinary film work reads only the relevant method and role. The references below are external sources, not additional Skills to download, install or load.

## Separate three questions

- **Capability:** the current visible page establishes available clicks; an exact read-only schema establishes callable fields; a version-specific official document establishes a dated vendor claim. Their scopes differ. A schema does not prove a web button or underlying engine identity.
- **Craft:** assess whether a method serves the approved story, observable performance, coherent space and edit. A tutorial preference is not a universal filmmaking requirement.
- **Permission:** being official, free to download or useful does not establish redistribution permission. The public package's MIT license does not cover external linked materials. See [third-party notices](../THIRD_PARTY_NOTICES.md).

## Platform facts and historical evidence

The public [platform snapshot](platform-state.json) keeps dated field names, ranges and limits for interpreting older project decisions. It does not contain reader credentials or prove that the reader has a connected MCP, installed CLI or matching UI. All shipped entries are historical references. The [freshness script](../scripts/check_platform_freshness.py) reports them as due for verification; offline film advice remains usable.

Important distinctions to keep:

- The official Cinema Studio Help Center attributes 4.0 to Seedance 2.5. The captured Studio schemas do not expose an underlying engine identity. Report the documentation attribution separately.
- Similar field names do not make Studio and standalone Seedance routes interchangeable. Exact reference limits and modes remain attached to their own dated schema.
- A historical 3.5 cost validator accepted a duration beyond the public UI limit. That is not proof that the longer shot can be generated.
- Image-model labels and IDs can disagree across interfaces. Recheck the selected route when its identity materially affects the recommendation.
- Metadata, a media URL, an Element name and text in a prompt are not evidence that an image was visually inspected or bound on the current page.

## Historical craft influences, not bundled source packs

Earlier private development studied ACTING SKILL.md, LIRA SKILL.md and CINEDANCE HIGGSFIELD SKILL.md from [HELL GRIND by Higgsfield Studio / Higgsfield Team](https://higgsfield.ai/original-series/hell-grind/episode-1). The project currently displays [OWL-P-NL-1.0](https://higgsfield.ai/licences/owl-p-nl-1.0). That permission is not MIT and is not a grant to republish a standalone prompt library. This public package includes none of those files, their translated full templates, or their media. Attribution records the development history; it does not assert endorsement or expand the source license.

Earlier work also consulted the downloadable guides linked from [case4k](https://higgsfield.ai/blog/case4k), [ai-vs-vfx](https://higgsfield.ai/blog/ai-vs-vfx), [cinematic headphones](https://higgsfield.ai/blog/cinematic_headphones), [car commercial](https://higgsfield.ai/blog/ai-car-commercial-youtube-guide), [Santiago breakdown](https://higgsfield.ai/blog/Santiago-breakdown) and [VFX](https://higgsfield.ai/blog/vfx_4k). No downloadable package is included. The Seedance adapters use dated capability facts and this project's shared shot methods rather than a mandatory vendor prompt sequence.

The public craft references are organized around this project's five responsibilities: approved decisions, usable assets, observable shot instructions, evidence-based review and edit continuity. Source-specific example scenes, prescribed template sequences, manual-style facial coding tables and a privately supplied seven-video transcription/OCR report are excluded. No external handbook or video report is a runtime dependency.
