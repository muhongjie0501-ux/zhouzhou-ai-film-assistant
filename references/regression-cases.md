# Maintenance regression cases

Read this file only when maintaining or reviewing this Skill, after a relevant rule changes. It is not a filming template, a mandatory five-role workflow, or a checklist to print for every shot.

These cases test decisions and evidence boundaries, not exact wording. Use the current candidate Skill and the smallest relevant evidence packet: the request, current project facts, and actual supplied images or inspected media when the case needs them. Do not invent an image inspection or platform check to make a case pass. No paid generation is required; a static pass cannot prove future model output will succeed.

## Cases

| Case | Input and evidence | Expected decision | Regression to reject |
|---|---|---|---|
| Simple shot | A generic, single-subject shot with one action and one camera idea; no identity, geography, or exact-dialogue requirement. | Use the minimum relevant role and references; deliver in the agreed project format. | Require all five roles, a new asset set, a full project scaffold, or an independent review merely because the film Skill was invoked. |
| Separate films | Two project directories share an actor but have different costumes, story decisions, and approved assets. Work is explicitly requested for the second film. | Resolve the requested project; import shared actor material only when explicitly selected, with the intended costume and state. Keep film-specific files in that project. | Infer the active film from a global last-used project, silently inherit the first film's decisions, or write project records into the Skill directory. |
| Single writer and approval | An executing role owns a draft. A reviewer identifies a blocking conflict and proposes a different action; the director has not approved the action change. | Reviewer delivers evidence and a proposed correction. The assigned writer updates its own document within authorization; changed story action remains a proposal until the director decides. Keep draft, generated, reviewed, director-accepted, and selected-for-edit facts distinct. | Reviewer overwrites the owner's draft, multiple agents concurrently update the same state file, or a review verdict becomes director approval or proof of generation. |
| Same Element, new image | An existing Element name contains an old quantity or costume description, but its image has been replaced and the director confirmed the new content. | Inspect or use recorded evidence of the current image version; preserve its valid call name while using the new confirmed content. Identify which dependent drafts need review. | Restore the old quantity from the name, silently assume the old image remains current, or declare previously adopted footage unusable solely because the asset changed. |
| Actual edit out-point | A generated clip continues beyond the portion selected for the edit. Its prompt planned a different ending from the selected out-point. | Editing/post provides the selected media version, interval, and observed visual/sound state at the actual cut. Shot execution carries only the necessary continuity into the next shot. If that cut is not yet chosen or inspected, label it provisional. | Treat the file's final frame or the prompt's planned ending as the confirmed edit out-point; claim uninspected sound continuity. |
| Reverse angle and lighting | A two-person exchange changes camera angle; a window is the established light source in the world. | Keep the real window, character positions, eyelines, and axis relationship coherent. Screen-left/right placement of the light may change with viewpoint. Check the actual reverse background and relevant reflection/occlusion. | Mirror the first image, freeze screen-relative light direction as a world fact, or invent an unseen reverse wall as already verified. |
| Show the actual image | A needed reference is accessible through a tool or an existing local file; the user wants to see and discuss it. | Inspect and display the actual image directly when supported, identifying what it can and cannot establish for this shot. Reuse the source or existing file. Necessary temporary transfer/cache is not a new deliverable. | Create a new permanent image copy, screenshot collection, or gallery just to display it; infer unseen details from the asset name; equate retrieved media with current webpage binding. |
| Intentional overlapping dialogue | The director explicitly requests natural interruption and overlapping reactions, with one line that must remain intelligible. | Preserve the overlap; state the motivated entry cue, whether the first speaker continues, the audible priority, and listeners' relevant behavior. Budget elapsed time with real overlap and necessary action. | A later sentence makes everyone else silent for the whole turn, enforces neat round-robin delivery, or removes the director's intended energy without approval. |
| Removed reference | A failed-shot repair removes a composition image that had provided seated posture, count, and a throwing direction. | Repair the principal cause and its necessary dependencies; determine which remaining evidence now provides each still-needed fact. Request or prepare only the genuinely missing input, or label a dependent draft conditional. | Remove the image and leave posture/direction unsupported, revive the rejected image unnoticed, or rewrite unrelated story and style choices. |
| No Start Frame slot | Current evidence shows a webpage with general References and Element mentions, without a dedicated Start Frame slot. An API schema separately lists a start-image field. | Give instructions for the observed surface; call the image an opening-composition reference and distinguish planned, existing, and bound assets. Reuse the current evidence unless a relevant change requires checking again. | Tell the user to use the absent slot, call a pasted mention a locked first frame, or generalize this page observation into a permanent limitation of every version. |
| Silent visual inspection | Only frames or a muted clip have been inspected; the task includes dialogue, accent, overlap, and music. | Report only supported visual findings and name the unverified audio requirements. If audiovisual acceptance is needed, obtain the relevant evidence through an available, authorized path. | Declare the spoken words, audible speaker identity, accent, overlap, lip sync, or music timing verified from silent pictures. |
| Unverified post-production capability | A request needs a timeline operation, audio edit, subtitle pass, grade, or export whose application/tool path has not been checked. | Distinguish editorial advice, inspected media facts, and executable operations. Verify the specific available path before claiming execution; retain an actionable plan when the operation is not yet supported. | Treat the existence of an editing/post role as proof of software access, promise an untested operation, or report an edited/exported result without output evidence. |

## Craft integration cases

Use these after changes to the acting, image or optical methods. They supplement the cases above; expected outcomes stay out of an independent evaluator's initial packet.

| Case | Input and evidence | Expected decision | Regression to reject |
|---|---|---|---|
| Deliberate stillness | Director requests a three-second silent look with no new gesture, prop or emotional turn. | Preserve the sustained performance and minimum shot structure. | Invent micro-actions, a hand task, a winner/loser or a beat quota. |
| Baseline adapted to context | A recognized recurring character paces when anxious; this shot requires remaining seated. A later approved injury changes the gait. | Use only relevant approved traits, allow a readable compatible outlet or no display of that habit, and respect the scoped story change. Store the baseline in the project under ①; actual take states remain with their owners. | Stand the character up, invent a fidget prop, copy the full profile, reject growth/injury or write film state into the Skill. |
| Voice and timing | A recurring voice has an approved accent/timbre; the actor has just run and now whispers. Another speaker remains offscreen; the director wants an interruption. | Keep identity, adapt bodily effort/delivery, preserve the audible offscreen speaker and intended overlap. Verify sound from suitable audio, not frames. | Freeze pace/loudness, assume a nonexistent Voice field, remove the offscreen voice or force round-robin dialogue. |
| Knowledge and physical causality | A character must visibly take a letter out, open it, then learn its contents. The director has not approved omitting these steps. | Preserve causal preparation/contact/reveal and react only to available information; propose a split if overloaded. | Start already grieving or holding an unexplained opened letter just to avoid a difficult transition. |
| Scoped image edit | Change a lamp's shade shape in a known image version while preserving the lamp position, people, room and source direction. | Specify the limited change and protected features while allowing necessary local shading/reflection/occlusion consequences; inspect the actual result before asserting preservation. | Redesign the room, require contradictory unchanged shadows or promise pixel-perfect success. |
| Asset purpose and missing view | Need a reverse-room angle, but the unseen wall has no verified reference. Other known landmarks must remain fixed. | Design the missing view as a proposal, preserve world geometry and lighting, and request only necessary assets. | Flip the source image, claim reconstructed 3D, invent verified geometry or mandate a multi-view package for every shot. |
| Optical information priority | Both faces and a story-relevant doorway must remain readable; current shallow-focus suggestions hide the doorway. | Reconcile camera/subject distance, framing and clarity with the approved story and actual controls; return a coverage change to ① if required. | Obey a lens label or numeric recipe at the cost of the required information, or introduce conflicting UI/prompt parameters. |

## Maintenance use

- Select the cases affected by the change, plus a simple-shot case when routing or delivery changes. Do not run every case for an unrelated typo.
- Record a short pass, issue, or not-evaluated finding and its evidence. Missing fixtures or unavailable tools are not a pass.
- Check that the rule has one authoritative home and that its callers agree. A regression case documents the intended behavior; it must not become a competing production rule.
- For an independent behavioral evaluation, give the evaluator the request and raw evidence first, without this table's expected answer. Compare its outcome with the relevant case afterwards.
