# 周周 AI 电影执行导演助理

一个电影 Skill 总入口，按需选择五个岗位。帮助导演把已确认的故事变成可拍摄、可检查、可剪辑的方案，保留导演的创作决定。公开整理版：**2.7.2-public.1**。

| 岗位 | 负责什么 | 交给下一岗位什么 |
|---|---|---|
| ① 导演规划与统筹 | 场景/镜头拆解、覆盖、调度、表演及全片和场景光影基调 | 已确认的镜头计划与资产需求 |
| ② 美术与资产制作 | 角色、场景、道具、必要角度的图片提示词及实际图片检查 | 有版本和用途的参考资产记录 |
| ③ 镜头执行 | 视频提示词、当前控件建议、生成结果记录与问题诊断 | 完整中英提示词、实际镜头及已知问题 |
| ④ 场记与独立审查 | 检查真实材料、连续性、提示词和交接 | 有证据的发现与需要哪一岗位处理 |
| ⑤ 剪辑与后期 | 选片、实际剪入剪出点、声音、调色、字幕与交付 | 剪辑建议或已核验的实际操作/输出 |

主入口是 [SKILL.md](SKILL.md)。专业指导在 `references/`，五岗位在 `references/roles/`；按当前任务读取，不必每次加载全部文件。

## 使用

把整个 `zhouzhou-ai-film-assistant` 目录按所用工具的 Skill 安装方式放入技能目录，不要只复制 `SKILL.md`。Codex 常用安装位置为 `~/.codex/skills/zhouzhou-ai-film-assistant/`。已有同名个人版时，先保留原版、比较差异，不要直接覆盖。此目录本身不会安装工具、登录账号或连接服务。

可这样开始：

> 使用 $zhouzhou-ai-film-assistant，担任①导演规划。项目目录是我指定的目录，只讨论当前场景如何拆镜头，先不要生成。

之后可让同一进程切换岗位，也可以让不同进程使用同一个项目目录。例如让②准备所需参考图提示词，再让③依据已确认资产写镜头提示词，④检查真实结果，⑤检查剪辑衔接。

各进程开始工作及交付前读取相关文件的最新版本；共享文件不会自动唤醒其他进程。每个权威记录只设一名写入者。影片剧本、提示词、素材和状态放在导演指定的影片目录，**不写入 Skill**。详见 [项目与交接规则](references/project-workflow.md)。

## 交付与边界

- 图片和视频提示词提供一份完整英文及一份完整中文译文；项目长提示词写入项目文件，聊天中保留讨论和文件链接。
- 参考图片默认留在平台，能直接查看时检查实际图片；不能把文件名或提示词当成看过图片。没有合适的查看能力时明确说明。
- 上传、绑定参考、点击生成及积分使用由用户手动完成。可在授权范围内只读检查平台；本 Skill 不自动生成或训练。
- 剪辑执行取决于实际可用的软件和授权，不因存在⑤岗位就承诺能控制达芬奇或输出院线成片。
- 平台控件与 API 信息带历史日期；首次安装不代表读者账号已核验。普通创作建议可离线完成。

本地资料日期检查（不联网、不写文件）：

```sh
python3 scripts/check_platform_freshness.py --json
```

公开副本默认报告 `DUE`，表示其中是历史资料，不能当作读者当前环境的验证结果。
